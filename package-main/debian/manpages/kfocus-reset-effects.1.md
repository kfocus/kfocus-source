# NAME
kfocus-reset-effects - reset effects and keyboard shortcuts

# SYNOPSIS
**kfocus-reset-effects**

# DESCRIPTION
**kfocus-reset-effects** is a utility that resets the keyboard shortcuts and settings to the Focus-prescribed defaults.

# OPTIONS
none
